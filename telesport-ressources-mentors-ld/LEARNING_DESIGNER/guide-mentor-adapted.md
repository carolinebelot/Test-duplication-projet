# Note d'accompagnement sur le projet

*![](image)*

Avant de commencer les sessions de mentorat sur cette mission, lisez **l'ensemble** du projet ainsi que les étapes.

**Contexte**

L'étudiant va développer **TéléSport**, une application web interactive qui permet de consulter l'historique des Jeux Olympiques et les performances des pays participants. Le projet utilise une stack moderne **React 19 + TypeScript + Vite + Tailwind CSS + React Router + Recharts**, et se concentre sur l'architecture front-end, la refactorisation de code et l'implémentation d'interfaces utilisateur complètes.

Il apprendra :

* Comment analyser, concevoir et refactoriser une architecture front-end React avec TypeScript
* Comment créer des Custom Hooks pour externaliser la logique métier et gérer l'état de l'application
* Comment implémenter une interface utilisateur complète avec navigation (React Router), visualisation de données (Recharts) et gestion d'erreurs

L'étudiant va travailler sur un projet complet en 2 exercices : d'abord en refactorisant une base de code existante pour améliorer sa structure et sa maintenabilité, puis en implémentant les fonctionnalités UI manquantes. Cette approche reflète une situation professionnelle réelle où il faut souvent reprendre du code existant avant d'ajouter de nouvelles fonctionnalités.

## **Conseils généraux**

L'objectif principal de ce projet est de développer les compétences en architecture front-end moderne avec React 19, TypeScript et les bonnes pratiques de développement.

Vous devez l'aider à :

* Comprendre les principes d'une architecture front-end modulaire et maintenable (séparation des responsabilités, réutilisabilité des composants)
* Maîtriser les concepts clés de React (Functional Components, Hooks, Custom Hooks) et TypeScript (interfaces, typage strict)
* Implémenter une navigation fluide avec React Router (routes dynamiques, paramètres d'URL, gestion 404)
* Intégrer des visualisations de données avec Recharts et créer une interface responsive avec Tailwind CSS

Si votre étudiant connaît déjà Angular, Vue ou un autre framework, profitez-en pour faire des parallèles et souligner les différences d'approche de React (approche fonctionnelle vs orientée objet, Hooks vs lifecycle methods, JSX vs templates). Cela l'aidera à mieux comprendre la philosophie React.

Gardez en tête qu'il s'agit d'un projet destiné à développer des compétences en architecture et refactorisation. Le projet n'est qu'un prétexte : si l'étudiant souhaite, par exemple, utiliser une autre bibliothèque de graphiques que Recharts ou encore personnaliser le design au-delà des maquettes fournies, il ne faut pas le bloquer.

Encouragez votre étudiant à s'appuyer sur les chapitres ciblés des cours proposés, comme suggéré dans les sections cours (notamment ceux sur les **Custom Hooks, TypeScript, React Router et l'architecture de composants**). En plus, encouragez-lui à expérimenter avec React lors du développement : tester différentes approches de gestion d'état, créer des composants réutilisables, explorer les React DevTools pour comprendre le cycle de rendu.

Enfin, préparez votre étudiant aux futurs projets en insistant sur l'importance de la documentation (fichier ARCHITECTURE.md, README.md complet), du typage strict TypeScript et des bonnes pratiques Git (commits clairs, repository bien structuré). Ces compétences seront essentielles pour les projets suivants et en milieu professionnel.

## Session de bilan

*![](image)*

Pour valider ce projet, l'étudiant n'a pas de soutenance avec un évaluateur.
C'est vous, en tant que mentor, qui allez valider son travail et le guider.

## **Préparez la session**

Une fois que votre étudiant a mis en ligne ses livrables, et avant la dernière session de mentorat :

* téléchargez le travail de l'étudiant pour prendre connaissance de son travail ;
* assurez-vous que tous les critères d'évaluation sont validés ;
* identifiez les éventuels points d'amélioration.

## **Menez la session**

Pour cette session, sélectionnez une **session de mentorat** classique.
Lors de votre compte-rendu sur la plateforme, nous vous conseillons de suivre ce modèle :

1. Bilan du projet sur la base du document d'autoévaluation de l'étudiant.
2. Points d'amélioration et recommandations.
3. Suggestions de ressources.
4. Encouragements / Félicitations sur les livrables et les qualités dont l'étudiant a fait preuve. Par exemple, sa rapidité à comprendre l'élaboration de tel livrable, le soin apporté aux détails dans un autre livrable...

Durant cette session :

* Faites remonter à l'étudiant les points sur lesquels il peut encore s'améliorer.
* Proposez-lui des ressources et donnez-lui des conseils.
* Évoquez les points sur lesquels il doit rester vigilant lors des prochains projets.

Si aucun des points n'est critique, ne le bloquez pas s'il souhaite passer au projet suivant.
